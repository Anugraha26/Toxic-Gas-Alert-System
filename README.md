# Toxic Gas Alert System

## Project Overview
This project is an Arduino-based toxic gas detection and ventilation system designed to detect harmful gases and automatically activate safety measures.

## Features
- Toxic gas detection
- LED alert indication
- Buzzer warning system
- Automatic ventilation fan control
- Real-time gas monitoring

## Components Used
- Arduino Uno
- MQ Gas Sensor
- Relay Module
- DC Fan
- Buzzer
- LED
- Jumper Wires

## Working Principle
When the gas concentration exceeds the threshold value:
1. LED turns ON
2. Buzzer sounds an alert
3. Ventilation fan starts automatically

## Applications
- Industrial Safety
- Laboratories
- Smart Homes
- Gas Storage Areas
